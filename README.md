## ✨ คุณสมบัติเด่นของระบบ

- 📱 **Responsive Design**: รองรับการใช้งานเต็มรูปแบบทั้งบนโทรศัพท์มือถือ แท็บเล็ต และคอมพิวเตอร์
- 🌓 **Dark / Light Mode**: เลือกระบบธีมมืดหรือสว่างได้ตามใจชอบ ถนอมสายตาขณะอ่านหนังสือ
- 🔍 **ระบบค้นหาและแยกหมวดหมู่**: ค้นหาตามวิชา ครูผู้สอน หรือคำสำคัญได้อย่างรวดเร็วในหน้าแรก
- 💡 **มีเฉลยพร้อมคำอธิบายแบบ Step-by-Step**: ช่วยให้นักเรียนเข้าใจเหตุผลของแต่ละคำตอบ ไม่ใช่เพียงจำตัวเลือก
- 🏠 **ปุ่มกลับหน้าหลักในทุกวิชา**: สลับทำข้อสอบแต่ละวิชาได้อย่างสะดวกรวดเร็ว

## 🚀 วิธีเปิดใช้งาน GitHub Pages

หากยังไม่ได้เปิดใช้งาน GitHub Pages ให้ทำตามขั้นตอนดังนี้:
1. ไปที่แท็บ **Settings** ของ Repository บน GitHub: `https://github.com/zannmansotuff/test/settings/pages`
2. ในหัวข้อ **Build and deployment** > **Source** ให้เลือก **Deploy from a branch**
3. ภายใต้ **Branch** ให้เลือกสาขา `main` และโฟลเดอร์ `/ (root)`
4. กด **Save**
5. รอระบบ GitHub Actions ทำงานประมาณ 1 - 2 นาที เว็บไซต์จะออนไลน์พร้อมใช้งานที่ [https://zannmansotuff.github.io/test/](https://zannmansotuff.github.io/test/)
